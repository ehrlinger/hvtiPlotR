# Test whether an object is an hvtiPlotR data object

Test whether an object is an hvtiPlotR data object

## Usage

``` r
is_hv_data(x)
```

## Arguments

- x:

  Any R object.

## Value

`TRUE` if `x` inherits from `"hv_data"`, `FALSE` otherwise.
